Progred is an editor where a program isn’t text. It’s structure: records, lists, blobs of raw bytes, and cells, stored as they are. Everything you see is a drawing of that structure, made by libraries. That one decision changes a lot, and this page takes it apart.

This forest is a program. Drag its slider to grow it; hold Ctrl and click a tree to find the code that drew it. Then switch off what the libraries draw, one layer at a time, and then the names, and watch what’s underneath.

Try: before you peel, click the 7f64 after tree count. Then peel all the way down. It stays selected the whole time, while its drawing changes from 7f64 to eight bytes.

The rest of this page opens the doors the peel walks past.

Door 1: what the parentheses mean

Parentheses mark a cell: a value with its own identity, stored once, that any number of places can point to. Cells, records, lists, and blobs are the only things Progred builds in. Functions are cells, their parameters are cells, and so is anything you share. Here, all three trees point at one (1f64).

Try: click one (1f64); the other two light up, because it’s one value. Change it to 0.5. Then look at the recipe: (x) and (height) are cells too, and every call’s labels point at them.

Door 2: names are labels

A cell’s name is only a fact stored about it: {name: "x"}. Calls don’t contain the word; they point at the cell. In the base view below, the call’s key is the cell’s identity, …10115: a random 128-bit id minted when the cell was created. Identities aren’t content hashes, so two cells with the same contents, or the same name, stay two different things.

Try: in the recipe, click x and rename it. Every call’s label follows. The base view doesn’t change at all.

Door 3: the same bytes, read four ways

Text, numbers, and colors aren’t built in either. Each is a library that recognizes a blob filed under a key it owns. Below, one cell holds four bytes, and four views file a copy under different keys: one no library knows, the text library’s, the color library’s, and the f32 library’s.

Try: click the bytes at the top and type new hex digits: every reading follows. Give it only three bytes, and the text still reads, but the color and the f32 decline and show you the record instead, because three bytes isn’t their convention.

Door 4: what the little f64 means

The subscript on a number is the name of the key it sits under: f64 means a 64-bit float, one of several number libraries. The subscript on an operator names whose arithmetic it is. There’s an f64 +, an f32 +, a u64 +, and a Fidget + that builds shapes instead of numbers. When you write a call, you pick one, and the tag is that choice, remembered.

Try: compare 0.1 + 0.2 in f64 and f32. A float doesn’t stand for one exact number but for a small range of them, and the editor writes the shortest decimal inside that range. In f64 the sum lands on the float just above the one for 0.3, and the shortest decimal in its range takes seventeen digits. In f32 the sum lands on the same float as 0.3, so it prints as 0.3. Drag the shape to turn it, and change a radius. Only f64 draws its calls between their operands; the f32 and u64 calls show what every call is underneath, a record.

Door 5: programs run before they’re finished

A call with a missing argument, or the wrong kind of value, doesn’t stop the program. It returns an absent: a value that says what’s missing and why, which the rest of the program can pass along or handle. or default is an ordinary function that recovers from one. The forest’s slider relies on it: before you touch the slider there’s no control state, and or default supplies 0.65f64.

Try: fill the empty x, and its absent becomes a number. Change 3 to a piece of text and read the reason. Nothing ever refuses your edit while you’re in the middle of it.

Door 6: views are programs

Every drawing you peeled off was a library’s view: a function from a value to a drawing. You can write one in Grap, Progred’s language, and keep it in the same document as your data. This one draws planets.

Try: change moons to 5. Then change the planet’s color inside planet drawing. (For now a Grap view draws a read-only picture next to the data; editing through it is future work.)
