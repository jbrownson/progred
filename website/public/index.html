Values, not text

Programs are made of values: text, numbers, lists. You edit them directly, so there’s no syntax to get wrong.

  1. 1Not yet completed: Rename the planet: click inside Mars and type a new name.
  2. 2Not yet completed: Give it a different number of moons.
  3. 3Not yet completed: Add a color: click the comma between two colors, type "blue" including the quotes, and press Enter.
  4. 4Not yet completed: Remove a color: double-click it to select the word, press Backspace to erase it, then Backspace once more to remove it.
  5. 5Not yet completed: Bring it back with Ctrl + Z.

Quotes make text and digits make a number: each value knows what kind it is.

One value, many places

A cell holds a value once. Every reference to it, shown in parentheses, is the same value.

  1. 1Not yet completed: Change either 7. Both change, because they’re one cell.
  2. 2Not yet completed: Make your own cell: click a comma and type (. Click the empty box inside it, type 11, and press Enter.
  3. 3Not yet completed: Reference it again: click another comma, then hold Ctrl and click a parenthesis around your new cell.
  4. 4Not yet completed: Change either 11. Its partner follows; the 7s don’t.

Parentheses select the reference; the inside edits the shared value.

Calculations

Calculations are values too, and each one shows its live result. Both use the parenthesized 3, a shared cell.

  1. 1Not yet completed: Change the 2 after +. Only the sum changes.
  2. 2Not yet completed: Change the shared 3. Every calculation using it updates.
  3. 3Not yet completed: Puzzle: make the sum and the product equal.
  4. 4Not yet completed: Puzzle: make the product exactly 100.

There’s no run button. Every result is always current.

Functions

A function is a calculation with a hole in it. scale multiplies its x by 2, and each call fills in its own x.

  1. 1Not yet completed: Change the first call’s 3. Only its result changes.
  2. 2Not yet completed: In the definition, change the multiplier 2. Both results follow.
  3. 3Not yet completed: Click x in the definition’s parameter list and give it a new name. Its uses and the call labels change too; the results don’t.
  4. 4Not yet completed: Put a call inside a call: in the second call, erase the 5 and press Backspace once more. Click the empty box, type scale, press Enter, and give the inner call a number.

References use identity, not spelling, so renaming keeps them connected.

Pictures are code

A picture is another view of code. dot draws a circle at x, and do runs its calls in order.

  1. 1Not yet completed: Move the first dot: change its 60. Only that dot moves.
  2. 2Not yet completed: In the dot definition, change the radius. Both dots change.
  3. 3Not yet completed: Add a dot: click the comma between the two dot calls, type dot, press Enter, and give it an x like 200.
  4. 4Not yet completed: Hold Ctrl and click any circle. The code that drew it is selected.

Inspired by Bret Victor’s Inventing on Principle.

Put it together

Three trees from one shared recipe: tree draws a trunk and a canopy at x with a height.

  1. 1Not yet completed: Make one tree taller: change the height in one tree call. Only that tree grows.
  2. 2Not yet completed: Click the green swatch in the tree definition and pick a new color. Every tree changes.
  3. 3Not yet completed: Plant a tree: click a comma between two tree calls, type tree, press Enter, and give it an x. Then click its empty height and give it one too.
